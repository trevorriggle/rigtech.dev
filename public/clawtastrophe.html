Clawtastrophe

Real physics, real odds, real bad decisions.

You walk into an arcade with $15. The claw machine is full of energy drinks, whiskey, cigarettes, scratchers and a few stacks of cash. The blackjack table pays 6:5, hits soft 17, and has never once lost money.

Play on itch.io ↗

How to break the house

  1. $15

    Start with fifteen dollars

    Spend it on the claw. Everything in the machine is a tool for beating the table. Learn the swing technique.

  2. 6:5

    A table built to win

    Blackjack pays 6:5 and hits soft 17. Whiskey and nicotine make you lucky; cigarettes let you double down.

  3. 5

    Rule Breakers

    Five of them are hidden in the machine, and each one permanently rewrites the table's rules.

  4. $5,000

    Buy the machine

    Get there and the claw machine is yours. Then have a talk with it.
